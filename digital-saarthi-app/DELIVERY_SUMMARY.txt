================================================================================
                        HOW TO USE THE API
================================================================================

1. CHECK ELIGIBILITY (IGNOAPS):
curl -X POST http://localhost:8000/check_eligibility \
  -H "Content-Type: application/json" \
  -d '{"scheme_id": "ignoaps", "age": 72, "bpl_status": true}'

Response: Eligible/Not Eligible with reason, benefits, next steps

2. CHECK ALL SCHEMES:
curl -X POST http://localhost:8000/check_all_schemes \
  -H "Content-Type: application/json" \
  -d '{"age": 72, "has_bpl": true, "is_farmer": false}'

Response: Eligibility for all 3 schemes with ranking

3. LIST SCHEMES:
curl http://localhost:8000/schemes

4. HEALTH CHECK:
curl http://localhost:8000/health

5. API DOCUMENTATION:
Open http://localhost:8000/docs in browser
